# Dodge The Block

A fast-paced 2D arcade game built in **C++** using **Raylib**, where the objective is simple: **survive as long as possible by dodging falling obstacles while earning coins to purchase powerful upgrades.**

This project was developed as a learning experience in game development, focusing on gameplay programming, UI systems, state management, audio integration, and modular game mechanics.

## Features

* Fast-paced dodge gameplay
* Four difficulty levels

  * Easy
  * Normal
  * Hard
  * Pro
* Coin collection system
* Upgrade store
* Health system
* Score tracking
* Pause menu
* Game Over screen
* Theme switching (Light/Dark)
* Dynamic background music
* Sound effects
* Temporary power-ups
* Modular game state management

## Store Upgrades

Players can spend earned coins to purchase upgrades such as:

* Increase movement speed
* Higher jump
* Temporary player shrink
* Additional health

Each upgrade becomes progressively more expensive, encouraging longer survival.
